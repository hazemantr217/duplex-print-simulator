# محاكي الطباعة وش وضهر (Duplex Print Simulator)

أداة تفاعلية للمصممين والمطابع لمعاينة ومطابقة طباعة الوجه والظهر في الكروت والكتيبات قبل الطباعة، لتجنب هدر الورق وضبط اتجاه تقليب الورقة في الطابعة.

## الميزات:
- محاكاة 3D لتقليب الورقة (الحافة الطويلة vs الحافة القصيرة).
- ترابيزة نور رقمية مع سلايدر شفافية ونمط فحص الفروق (Difference Mode).
- إمكانية لصق الصور مباشرة من الحافظة باستخدام اختصار Ctrl + V.
- معايرة ترحيل الطابعة بالمليمتر (X/Y Offset).
- محاكي طي الكتيبات والملازم.

## طريقة التشغيل:
افتح ملف index.html في أي متصفح ويب.
